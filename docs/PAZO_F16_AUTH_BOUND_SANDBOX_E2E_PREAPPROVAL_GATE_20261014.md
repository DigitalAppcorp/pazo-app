Si el proveedor omite ese dato, **STOP y CANCELAR, sin atribuir owner ni beneficios**, en vez de asumir una cantidad. Ninguna segunda cuenta ni suscripción para compensar un error. Una vez `--validate-remote` PASS, el paso `--run` repite la lectura de seguridad inmediatamente antes de reservar el ensayo autorizado.
